# Modern CMS – Next.js Frontend

This is a Next.js (App Router) application that implements:
- SSR/ISR pages for blogs and health
- Client pages for login/register/profile/themes/notifications/admin
- WCAG 2.1 AA accessibility patterns
- Theming with light/dark and live customization preview
- Role-based navigation, notification toasts, and error/loading states

## Quickstart
1. Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_API_BASE_URL`.
2. Install deps: `npm install`
3. Run dev: `npm run dev`
4. Open http://localhost:3000

See FRONTEND_ONBOARDING.md for details.
